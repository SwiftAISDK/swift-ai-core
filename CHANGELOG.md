# Changelog

## 1.2.0

- Experimental AISteering + never-throwing delivery receipts and idempotent IDs; generateText/streamText, agent and Swift-native options forward steering. Steering append/prepareStep replacement, current/initial/response request state, per-step delivery metadata, final-answer selection, structured streaming boundaries, no continuation after interruption/error or unresolved tool results. Typed onStepError callback with real step number, previous steps, request/model identity and error; once-only stream failure closure and telemetry stepError. Agent onError before rethrowing original ordinary error, onAbort only on streaming cancellation/timeouts; native cause traversal up to four links. Telemetry aiVersion on copied events plus both model/tool execution contexts. fixJson does not retain incomplete minus as the first array element. AIModelFeatureSupport, AIModelCapabilities, AIModelEntry<RequestConfiguration>, AIProviderOptionDefinitions and AIModelProviderOptions native equivalents; no conflict with existing ModelCapability operation enum. Codable capability/support/section/option types preserve omitted vs false vs unknown vs conditional, optional configuration and realtime transport/connection names. Port shared async credential resolution and reasoning mapping: optional/default/override handling, closest supported effort, none-budget warning and percentage defaults. Swift-native Foundation/Sendable protocols replace JS Resolvable/promises; browser, Node, Zod and package loader mechanics remain outside the native product. Reviewed upstream: ai 7.0.153 to 7.0.159, @ai-sdk/provider 4.0.34 to 4.0.35, @ai-sdk/provider-utils 5.0.68 to 5.0.72. Validation passed: node Scripts/test-packages.mjs (all 52 owning package suites and the compatibility facade); node Scripts/sdk.mjs generate --check; node --test Scripts/tests/*.test.cjs (27 passed); docs-site check and build (100 pages). Live provider calls were not run.
  Compatibility: Minor release for additive native API; existing static settings and call sites remain compatible. Updated direct dependency minimums are recorded in the manifest. Existing documented JS/framework and native product gaps remain; version-delta review does not imply full parity or live-service testing.
